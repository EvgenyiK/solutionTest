# Тестовое задание (АйТи-Солюшн)

Программа на языке Go, которая перебирает целые числа от `0` до бесконечности и выводит первые `N` чисел, делящихся без остатка на количество своих разрядов.

## Требования

Для запуска из исходного кода потребуется установленный компилятор [Go](https://go.dev) (версии 1.18 или выше).

## Как запустить

1. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd solutionTest
   ```

2. Запустите программу напрямую:
   ```bash
   go run main.go
   ```

3. Введите желаемое количество чисел `N` (например, `28`, `120` или `500`) и нажмите **Enter**.

## Сборка исполняемого файла (опционально)

Если нужно собрать автономный бинарный файл:

```bash
go build main.go
```

После сборки запустите полученный файл из терминала:
* **Windows:** `.\main.exe`
* **Linux / macOS:** `./main`
